# Taller de Ejercicios: Lógica de Repetición en DataLab

Aplica los conceptos de la Semana 5 para resolver los siguientes retos técnicos. Todos los ejercicios deben ser implementados como funciones que puedan integrarse al menú principal de DataLab.

## 🧩 Reto 1: El Contador de Registros Válidos (Uso de `while`)
**Contexto:** DataLab necesita procesar una lista de edades de usuarios, pero el usuario no sabe cuántas edades ingresará.
**Objetivo:** Crear una función donde el usuario ingrese edades una por una. Si ingresa un número negativo, el programa debe detener la captura y mostrar el total de edades válidas ingresadas.
*   **Pista:** Usa un ciclo `while` y una variable contador.

## 🧩 Reto 2: El Procesador de Lotes (Uso de `for`)
**Contexto:** DataLab recibe un "lote" de 10 sensores de temperatura.
**Objetivo:** Implementar un ciclo `for` que simule la lectura de estos 10 sensores. Por cada lectura, el programa debe imprimir: *"Sensor [N]: Temperatura procesada"*. Al final, debe imprimir un mensaje de *"Lote completo"*.

## 🧩 Reto 3: Validador de Contraseña de Acceso (Simulación `do-while`)
**Contexto:** Para entrar a las funciones avanzadas de DataLab, se requiere una clave: `"Data2026"`.
**Objetivo:** Crear un sistema que solicite la contraseña. Si es incorrecta, debe mostrar *"Acceso denegado, intente de nuevo"* y volver a pedirla inmediatamente. Solo debe salir del ciclo cuando la contraseña sea correcta.
*   **Pista:** Usa `while True` y `break`.

## 🧩 Reto 4: El Filtro de Datos (Combinación `for` + `if`)
**Contexto:** Tienes una lista predefinida de valores: `[10, 55, 2, 80, 15, 100, 40]`.
**Objetivo:** Usar un ciclo `for` para recorrer la lista y mostrar únicamente los valores que sean mayores a 50. Para los valores menores, debe imprimir *"Valor descartado"*.
