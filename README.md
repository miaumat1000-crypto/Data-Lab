# DataLab

Proyecto integrador del curso de Lógica Computacional.

## Descripción

DataLab es una aplicación desarrollada progresivamente durante el semestre
para aplicar conceptos de algoritmia y programación en Python a problemas
relacionados con el procesamiento básico de datos.

DataLab es una aplicación que permite cargar o ingresar conjuntos de datos, aplicar reglas básicas de validación, identificar registros con problemas, clasificar información y generar estadísticas y reportes básicos sobre la calidad y características de los datos.
